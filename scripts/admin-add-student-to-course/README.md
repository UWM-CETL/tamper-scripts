
# README for `admin-add-student-to-course.user.js`

## What it does
Adds an **“Special Enrollment”** button to every User Admin page. Click to automatically complete
a workflow which adds the user to a course via a section crosslisting through an intermediate course.

## Installation
[Install this script](https://uwm-cetl.github.io/tamper-scripts/scripts/admin-add-student-to-course/admin-add-student-to-course.user.js)

## Using it
* Be an admin with Teacher acess (or greater) to both an intermediate course and the destiation course.
  * RECOMMENDED: Use a dedicated intermediate course for all enrollments of this type.
* Visit the highest-level subaccount possible.
* Go to the Users page, and view the details of the user which needs to be enrolled.
* Click the "Special Enrollment" button on the right side of the page.
* Answer the prompts.

Be sure to have the Canvas Course ID number for both the intermediate course, and the destination 
course. 

After the section is crosslisted, you will be taken to the Section Edit page in the destination course.

## Updating / removing

Your script manager will alert you when a newer version is available.
Disable or delete the script from the manager’s dashboard at any time.
